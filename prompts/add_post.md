# WordsView 포스트 생성 프롬프트

다음 주제들에 대한 마크다운 포스트를 `_posts/` 디렉토리에 생성해줘:

## 생성 조건
- **파일 형식**: `YYYY-MM-DD-title-in-english.md` 형식으로 파일명 생성
- **날짜 범위**: 2024-01-01 ~ 2025-09-27 사이에서 기존 포스트와 겹치지 않도록 적절히 간격을 두고 설정
- **내용 길이**: 기존 포스트처럼 간략하게 2-3문장으로 작성
- **번역어**: 영어 등 원어를 반드시 명기 (예: Echo Chamber Effect, Regression to the Mean)

## 포스트 구조
```yaml
---
layout: post
title: 한글 제목
tags: [태그1, 태그2, 태그3]
references: (선택사항)
  - title: "영문 제목"
    url: "위키피디아 또는 관련 링크"
  - title: "한글 제목"
    url: "한글 위키피디아 링크"
---

간단한 정의나 설명 한 줄. 원어명 표기

2-3문장으로 개념 설명 및 실생활 적용 예시. 구체적이고 이해하기 쉬운 예시 포함.
```
